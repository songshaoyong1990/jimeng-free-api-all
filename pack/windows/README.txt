即梦 AI 免费接口服务 - Windows 便携版
================================

【使用方法】
1. 解压整个文件夹到任意位置（路径尽量不要含特殊字符）
2. 双击 StartJimeng.bat（启动即梦服务）
3. 浏览器会自动打开 http://127.0.0.1:8000
4. 首次使用按网页提示设置管理员密码
5. 在控制台里配置即梦 Session（即梦官网登录后的 sessionid）

【停止服务】
双击 StopJimeng.bat（停止即梦服务）

【注意事项】
- 不需要安装 Node.js 或其它开发环境
- 数据保存在 data 文件夹（数据库、配置等）
- 日志保存在 logs 文件夹
- 关闭标题为「即梦服务运行中」的黑色窗口也会停止服务
- 若 8000 端口被占用，请联系技术人员修改配置

【API 地址】
http://127.0.0.1:8000

请求头示例：
Authorization: Bearer <你的即梦sessionid>
