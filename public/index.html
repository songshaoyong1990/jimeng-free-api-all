RunningHub 配置

对齐 infinite-canvas「渠道 → RunningHub」：先配 Key 与目录，再用 OpenAI 生图接口调用。
  1. 填写 RH 币 API Key（消费级）；企业再填余额 Key
  2. 导入默认目录，或粘贴官网 /run/ai-app/...、/run/workflow/... 链接
  3. 启用要用的应用/工作流，可设默认模型
  4. OpenAI 兼容：POST /v1/images/generations（可带 n/size/quality/images）， 参考图也可用 POST /v1/images/edits； model 用 app:id / workflow:id

本地 ComfyUI

对齐「渠道 → RunningHub」用法：导入 ComfyUI「另存为 API」JSON，启用后用同一套 OpenAI 生图接口调用。
  1. 填写本机 ComfyUI Base URL（默认 http://127.0.0.1:8188），可点「测试连通」
  2. 导入 API JSON（文件或粘贴），自动分析字段 / 图槽 / 提示词槽
  3. 启用工作流 → 可「编辑节点」「查看 API」，与 RunningHub 一致
  4. POST /v1/images/generations， model 用 comfy:工作流id； 节点参数与 OpenAI 映射以管理台保存为准

导入 / 工作流目录

启用后会出现在默认模型下拉，并出现在 GET /v1/models。导入会解析节点 inputs（跳过连线），推断 prompt / image 角色。

请求参数

对应 POST /v1/videos/generations： model · prompt · ratio · resolution · duration（或 seconds）· 首尾帧 image/images/file_paths · response_format。 不含生图字段 n/size/quality。
H3 多参考：图片→image，视频→video，音频→audio（按选择顺序对应 <Picture/Video/Audio N>）
